# Sobre o projeto

Este projeto é o trabalho final da disciplina de Matemática Computacional Aplicada e simula uma calculadora científica utilizando HTML e JavaScript.

---

# Funcionalidades

- Cálculo básico (adição, subtração, multiplicação e divisão)
- Função (f de x, tabela de valores para um intervalo de x e domínio inválido)
- Matriz (soma e subtração, multiplicação por escalar, compatibilidade de dimensões, determinante e transposta)
- Análise Combinatória (fatorial, permutação, arranjo e combinação)
- Conversão de Bases (binários, octal, hexadecimal, decimal)
